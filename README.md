# Rust-Arduino-Macro-Epririence-
Experience — компактный инструмент для настройки и управления автоматизированными сценариями. Поддерживает подключение Arduino через COM-порт, профили конфигураций, настройку чувствительности, ADS, FOV и других параметров. Современный интерфейс объединяет все основные функции в одной панели управления.
